# Eswatini Scholars Network — Enhanced App

Updated features:

- **Scholarships**: Filter by Academic or Sports. Status labels auto-recalculate based on the current date. New scholarships can be added by the administrator.
- **Schools**: Tap any school to open a detail view with a Google Maps link to its location. (Photos can be expanded later.)
- **Resources**: When publishing, choose type — Notes, Past Papers, Marking Schemes, Examiner’s Reports, or Other. Shown in the list.
- **Requests**: Users can submit resource requests (with optional subject). Administrator can Approve or Decline them in the Admin section. (Stored on this device in the prototype; Supabase needed for cross-device sharing.)
- Admin access remains restricted to the builder account only.

All previous content and functionality preserved.

To update the live site: Extract and redeploy the folder to your Netlify project.
